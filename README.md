# NU Word Grasping Game
### เกมเรียงคำเพื่อการบริหารมือและสมอง

เกม AR บนเว็บเบราว์เซอร์ สำหรับฝึกการเคลื่อนไหวแขนและมือร่วมกับการรู้คิด
ผู้เล่นใช้มือผ่านกล้องเว็บแคมหยิบการ์ดคำศัพท์มาเรียงให้เป็นประโยคภาษาไทยที่ถูกต้อง
พร้อมบันทึกข้อมูลการเคลื่อนไหวเพื่อให้นักกิจกรรมบำบัดติดตามความก้าวหน้า

**เล่นได้ที่:** https://rattapoomw.github.io/handwordgame/

โดย รัฐภูมิ วรานุสาสน์ · มหาวิทยาลัยนเรศวร

## คุณสมบัติ

- ตรวจจับมือด้วย **MediaPipe Hands** — จีบนิ้วหรือกำมือเพื่อหยิบ แบมือเพื่อปล่อย
- ใช้ **เมาส์หรือทัชสกรีน** แทนได้เมื่อไม่มีกล้อง
- คลังประโยค **299 ประโยค** (3 / 4 / 5 คำ) ตรวจสอบแล้วว่าแต่ละข้อมีคำตอบที่ถูกต้องเพียงแบบเดียว
- โหมดซ่อนประโยคโจทย์ เพื่อเพิ่มการฝึกด้านการรู้คิด
- ระบบคะแนนที่หักตามคำที่วางผิดและให้โบนัสเมื่อตอบถูกต่อเนื่อง คะแนนรวมไม่มีวันลดลง
- ต้องค้างมือไว้ครู่หนึ่งจึงจะหยิบการ์ดที่วางอยู่แล้วได้ กันการเผลอชนการ์ดหลุดตอนถอนมือ
- ทดสอบเปิด–ปิดมือ 10 วินาทีก่อนเริ่มเล่น เพื่อวัดพิสัยนิ้วพื้นฐาน
- **3 แบบภาพ**: กล้อง / พื้นดำ / พื้นขาว สลับได้ระหว่างเล่น (ปุ่ม “ภาพ” หรือกด V) สำหรับผู้ที่มองเห็นไม่ชัด — วงกลมบอกสถานะแยกด้วยรูปร่างด้วย ไม่ใช่แค่สี
- บันทึกข้อมูลลง **Google Sheet** พร้อมแดชบอร์ดสำหรับนักกิจกรรมบำบัด — ผู้ป่วยแต่ละคนมีไฟล์ของตัวเอง ประวัติจึงไม่ขาดตอน
- ทำงานได้แม้ไม่มีอินเทอร์เน็ต — ข้อมูลจะถูกเก็บไว้และส่งอัตโนมัติเมื่อกลับมาออนไลน์

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกม |
| `dashboard.html` | แดชบอร์ดติดตามผลสำหรับนักกิจกรรมบำบัด |
| `config.js` | **ตั้งค่าทั้งหมดที่นี่** — URL, ความยาก, เกณฑ์การจับ, คะแนน ฯลฯ |
| `thai_sentences.js` | คลังประโยค |

## การติดตั้ง

วางไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน เปิด `index.html` ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
กล้องจะใช้งานได้เฉพาะเมื่อเปิดผ่าน `https://` หรือ `localhost` เท่านั้น

### เชื่อมกับ Google Sheet (ถ้าต้องการบันทึกข้อมูล)

1. สร้าง Google Sheet ใหม่ (ว่างเปล่า — ไม่ต้องตั้งชื่อคอลัมน์เอง) → **Extensions ▸ Apps Script**
2. วางเนื้อหาไฟล์ `apps_script_stats.gs` แล้วบันทึก
3. ตั้งค่า `ADMIN_KEY` ในสคริปต์ หากต้องการใช้ปุ่มลบข้อมูลผู้ป่วยจากแดชบอร์ด
4. **Deploy ▸ New deployment ▸ Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` มาใส่ในช่อง `endpoint` ของ `config.js`

> เมื่อแก้ไขสคริปต์ในภายหลัง ต้อง **Deploy ▸ Manage deployments ▸ ✏️ ▸ New version** ทุกครั้ง
> มิฉะนั้น URL เดิมจะยังใช้โค้ดเวอร์ชันเก่า — การสร้างไฟล์ผู้ป่วยใหม่หรือการบันทึกข้อมูลไม่ต้องทำขั้นตอนนี้ เกิดขึ้นอัตโนมัติทุกครั้งที่มีคนเล่น

## โครงสร้างข้อมูล — ไฟล์เดียวต่อผู้ป่วยหนึ่งคน

Google Sheet ที่ผูกกับสคริปต์ (“hub”) **ไม่เก็บข้อมูลดิบ** มีแท็บเดียวชื่อ `patients`
เก็บสรุปสั้น ๆ ต่อผู้ป่วยหนึ่งแถว (ชื่อ ลิงก์ไฟล์ จำนวนครั้งที่เล่น แนวโน้มล่าสุดแบบย่อ)
เพื่อให้หน้ารายชื่อผู้ป่วยในแดชบอร์ดโหลดเร็ว โดยไม่ต้องเปิดไฟล์ของทุกคน

เมื่อผู้ป่วยเล่นครั้งแรก ระบบจะ **สร้างไฟล์ Google Sheet ใหม่ให้อัตโนมัติ** สำหรับผู้ป่วยรายนั้นโดยเฉพาะ
มีแท็บ `log` เก็บทุกแถวข้อมูลของผู้ป่วยคนนั้นตลอดไป **ไม่ว่าจะเล่นกี่ครั้งหรือผ่านไปกี่ปี**
และหากในอนาคตมีเกมอื่นเพิ่มเข้ามา ข้อมูลของเกมนั้นก็จะเก็บในไฟล์เดียวกันนี้ (แยกด้วยคอลัมน์ `game`)
ประวัติของผู้ป่วยแต่ละคนจึงไม่มีวันถูกตัดขาดหรือกระจายไปคนละไฟล์

ไม่ต้องแก้สคริปต์เมื่อมีผู้ป่วยใหม่ หรือเมื่อไฟล์ผู้ป่วยคนใดโตขึ้น — เกิดขึ้นเองทั้งหมดตอนรัน

**คอลัมน์ `type` ในแต่ละแถว:**

- `session` — คะแนนรวม ด่านที่ผ่าน ระดับที่ทำได้ เวลาที่ใช้
- `round` — เวลาคิด เวลาแก้โจทย์ จำนวนคำที่เรียงถูก/ผิด
- `movement` — จลนศาสตร์ของการเอื้อมแต่ละครั้ง (ความตรง ความนุ่มนวล ความเร็ว การจับ–ปล่อย)
- `pinchcheck` — ผลทดสอบเปิด–ปิดมือก่อนเริ่มเล่น

### จัดการข้อมูลผู้ป่วยจากแดชบอร์ด

หน้าผู้ป่วยแต่ละคนมีปุ่ม **⬇️ CSV ผู้ป่วยที่เปิดอยู่** (สำรองข้อมูลก่อนลบ) และ
**🗑 ลบผู้ป่วยรายนี้ถาวร** (ลบไฟล์ทิ้งจริง ต้องมี `ADMIN_KEY` และพิมพ์ยืนยันคำว่า `DELETE`) — ไม่มีปุ่ม “ลบทั้งหมด” เพราะแต่ละคนแยกไฟล์กันอยู่แล้ว

## การตั้งค่า

แก้ที่ `config.js` เท่านั้น ไม่ต้องแก้ไฟล์ HTML

```js
endpoint : 'https://script.google.com/macros/s/…/exec',
game: {
  questionsPerStage : 5,        // จำนวนข้อต่อด่าน (3 ด่าน)
  revealSentence    : false,    // แสดงประโยคโจทย์ตั้งแต่ต้นหรือไม่
  showScore         : true,     // แสดงคะแนนระหว่างเล่น
  theme             : 'camera', // 'camera' | 'dark' | 'light'
  pointsByLength    : { 3: 60, 4: 80, 5: 100 },
  slotPickHoldMs    : 700,      // ต้องค้างมือไว้เท่านี้ (ms) จึงหยิบการ์ดที่วางแล้วได้
},
grip: { close: 0.62, open: 0.95 },   // ยิ่งค่า close สูง ยิ่งจับง่าย
```

## ⚠️ ข้อจำกัด

ข้อมูลจากกล้องเว็บแคมแบบไม่ติดมาร์กเกอร์ **ใช้เปรียบเทียบการเปลี่ยนแปลงของผู้ป่วยรายเดิมข้ามครั้งเท่านั้น**
ไม่ใช่แบบประเมินมาตรฐาน **วัดแรงบีบมือไม่ได้** และไม่ควรใช้เทียบระหว่างบุคคลหรือเทียบกับค่าปกติ

แนะนำให้ใช้รหัสผู้เล่น (เช่น `P-001`) แทนชื่อจริง และเก็บตารางเทียบรหัสไว้แยกต่างหาก
ไฟล์ Google Sheet แต่ละไฟล์เข้าถึงได้โดยผู้ที่มีสิทธิ์ในบัญชี Google ที่ deploy สคริปต์เท่านั้น
